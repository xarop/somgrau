# WordPress Project

Este repositorio contiene una instalación de WordPress.

## Estructura
- `wp-admin/`, `wp-includes/`, `wp-content/`: Carpetas principales de WordPress.
- `wp-content/themes/`: Temas.
- `wp-content/plugins/`: Plugins.

## Notas
- No subas archivos sensibles como `wp-config.php` o la carpeta `uploads`.
- Utiliza el archivo `.gitignore` para evitar subir archivos innecesarios.
